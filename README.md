# Meu portfólio profissional

Desenvolvi meu portfólio com **Astro, TypeScript, Tailwind CSS e GSAP**, reunindo tecnologias que me permitem criar uma experiência visual personalizada e apresentar minha trajetória como desenvolvedor web Full Stack.

Escolhi o **Astro** para gerar as páginas em HTML estático e organizar a interface em componentes reutilizáveis. Com **TypeScript**, estruturei os dados do portfólio e as interações com tipagem, tornando o código mais claro e fácil de manter.

Utilizei **Tailwind CSS 4 e CSS** para construir os layouts responsivos, definir os tokens visuais e trabalhar a identidade do site. As fontes são hospedadas localmente, e os estilos concentram as decisões de cores, tipografia e espaçamento.

Com **GSAP**, desenvolvi as animações de entrada, as transições e os movimentos vinculados à rolagem. Também considerei a preferência por movimento reduzido, para que a experiência se adapte a quem utiliza essa configuração.

Integrei o **PDF.js** para permitir a leitura do meu currículo dentro do site, com zoom e texto selecionável. O leitor é carregado sob demanda, quando o visitante abre o documento.

Esse projeto reúne meu trabalho com componentes, estilos, animações e integração de recursos em uma experiência que representa minha atuação profissional.
